# История промежуточного S4

Коммиты `a5760c9` и `be91fda` содержали закрытый reader и временный интерфейс
SharedFacts без интеграции S3. Их прежний статус незавершённой интеграции относится
именно к этим коммитам.

Текущий контракт, ограничения, CLI и проверка интеграции описаны в
[ADR-010 S4](adr-010-s4.md). Временный интерфейс удалён; используется общий расчёт
S3. Production-приёмка не заявляется.
