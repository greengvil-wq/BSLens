# Проверки R01

Статус: проверки исполнены в облачной Linux-среде. Независимое ревью ещё требуется.
Не утверждается готовность полного ядра, MCP, Windows-поддержки или совместимость с БСП.

## Исполненные команды

- `cargo test --locked --features synthetic-dev`: 7 тестов успешно, 0 ошибок
  (1 модульный, 1 блокировки production, 5 интеграционных).
- `cargo test --locked`: 1 тест блокировки production успешно; экспериментальный
  модуль и его тесты не входят в эту сборку.
- `cargo build --locked`: успешно.
- `cargo fmt`: применено к исходникам.

Проверены точное совпадение metadata и source с внешним Python-эталоном, BOM, CRLF,
кириллица и supplementary Unicode, физические byte offsets, пустой источник,
пределы 100 строк/16384 байта, несовпадающий snapshot_id, schema_version/user_version,
повреждение источника и позиций, inventory/manifest, повреждённый SQLite, пути и
символические ссылки, неизменность байтов файла после чтения, отсутствие sidecar-файлов,
маркировка экспериментального CLI и отказ штатного CLI без вывода данных.

Файл `tests/fixtures/schema4.json` содержит только авторские данные. Бинарных снимков
в репозитории нет: Rust-тесты создают SQLite во временном каталоге и удаляют его.
Внешний Python-эталон сформировал снимок и ожидаемые значения из временного Git-репозитория:

- commit: `5442d2f3ab034d77219be826d33b331a3f1000cf`;
- snapshot: `bslens-v4-6ae8ca133d0c80b5417bc7580aef97b71a326f5b8325623e3670cfa2ed896d99`;
- источник `Пример.bsl`: BOM, комментарий с emoji, процедура, CRLF/LF, русский комментарий;
- источник `Empty.bsl`: пустой файл.

Это общий авторский вектор сравнения, а не экспорт пользовательской БСП. Python-код
эталона не включён в Rust-проект, и тесты Rust его не вызывают. Проверка всего корпуса
Python и повторная реализация всех его отказов в R01 не заявляются.

## Средства сборки

Использованы rustc 1.85.1 (4eb161250 2025-03-15), cargo 1.85.1
(d73d2caf9 2024-12-31), официальный rustfmt из той же версии. Они изначально отсутствовали
в PATH. Компоненты скачаны с `static.rust-lang.org`, SHA256 сверены с официальным
`https://static.rust-lang.org/dist/channel-rust-1.85.1.toml`, распакованы в изолированный
каталог вне проекта. Установочные скрипты, rustup bootstrap, elevation, изменение
profile/ОС/реестра не применялись. Cargo cache также вне проекта.
