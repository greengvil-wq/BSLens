# ADR-053. Владельцы встроенных команд

Linux: `build-navigator-owners`, профиль `linux-v5-navigator-owners1-xml221-r09`.
Лексическая версия и правила обработки исходников Навигатора не изменяются.

Для каталога, документа и регистра сведений связь появляется только при
наличии уже проверенной непосредственной XML-декларации `Command` в
родительском дескрипторе и BSL по точному пути
`<Объект>/Commands/<Имя>/Ext/CommandModule.bsl`. Регистр, имя и путь
не нормализуются. Связь содержит существующий ключ декларации, а не
ключ, выведенный из имени файла. Спорные XML-объявления по-прежнему
отклоняются при сборке. Без декларации или при несовпадении содержимого
каталога модуль остаётся с неподтверждённым владельцем; отсутствие BSL
не создаёт связи и не удаляет XML-декларацию.

Правило одинаково для сборки и автономного `verify`. Оно не меняет
прежние связи команд других семейств и не применяется при проверке
старых снимков. Лексические факты, ветки и диагностические аномалии
сохраняются как в профиле-предшественнике.
