# Проверки R02

Объём: только узкий библиотечный XML 2.21 слой, авторские данные, облачная Linux-среда.
R01 остаётся исходным родительским коммитом, production API не открывался.

## Авторский эталон

В `tests/fixtures/xml221` находятся Configuration, Catalog, Document,
InformationRegister и два коротких BSL-модуля из ранее авторских synthetic fixtures.
Версия XML заменена на 2.21. `expected.json` получен внешним Python-эталоном
`xml_adapter.inspect(..., policy="structural-2.21")` для этих файлов.
Rust сравнивает путь, тип, имя, UUID и точные module bindings для всех четырёх объектов.
Это ограниченное differential-сравнение, не доказательство полной эквивалентности.
Программный код Python в проект не добавлен и при Cargo tests не запускается.

## Восемь групп XML-тестов

1. Сравнение структуры с Python и воспроизводимый порядок объектов.
2. Модули корня и отдельные непривязанные модули без угадывания владельца.
3. Namespace prefixes, BOM, комментарии внутри скалярного имени; двойной BOM отвергается.
4. DTD/внешние entities, PI, не-UTF-8 declaration, invalid UTF-8, неизвестная entity,
   malformed XML. Нет сетевого/файлового разрешения сущностей.
5. Namespace, версия 2.20 вместо 2.21, точный регистр пути/имени, отсутствующие
   дескрипторы, абсолютные/небезопасные адреса.
6. Дубликаты ссылок/Name/UUID, неправильный UUID и идентификатор.
7. Неподдержанный класс, известная вложенная сущность и orphan XML — явные отказы.
8. Лимиты числа файлов, суммарного/одиночного размера, глубины, числа событий и узлов.

Все проверки используют только переданные bytes, без доступа к базе, рабочей копии,
Windows или пользовательским исходникам. Тесты Rust создают лишь авторские структуры.

## Контракт отказа

`XmlError` содержит `Code` и точный адрес входного документа (либо пустую строку для
общего лимита входа). Коды:

- `Limit`, `Path`: ограничения ресурсов/адресов;
- `Utf8`, `Encoding`, `Dtd`, `ProcessingInstruction`, `Malformed`: транспортный XML-слой;
- `Namespace`, `Version`, `Shape`: неподдержанная оболочка;
- `Identifier`, `Uuid`, `Duplicate`, `NameMismatch`: идентичность;
- `Missing`, `UnsupportedType`, `NestedUnsupported`, `OrphanXml`: неполный или
  неподдержанный структурный набор.

Отказ не возвращает частичную структуру. При нескольких ошибках гарантируется отказ,
но не приоритет конкретного кода. `unverified` у успешного результата — непроверенные
свойства/атрибуты, а не признание полноценной схемы. Привязка BSL подтверждает только
наличие точного разрешённого адреса, не валидность тела или его происхождение Git.

## Результаты исполнения

Исполнено на том же изолированном Rust 1.85.1, что и R01:

- `cargo test --locked --features experimental-xml`: 9 успешно (8 XML + production gate).
- `cargo test --locked`: 1 успешно; оба экспериментальных слоя выключены.
- `cargo test --locked --all-features`: 15 успешно (8 XML + 7 R01).
- `cargo fmt -- --check`, `git diff --check`: успешно.

Независимое ревью требуется отдельно. Закреплены quick-xml 0.37.5 и roxmltree 0.20.0,
их контрольные суммы включены в Cargo.lock; Rust toolchain не изменялся.
Ни одна из проверок не подтверждает поддержку production/BSP или полного профиля Python.
