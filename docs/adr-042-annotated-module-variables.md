# ADR-042: Смежная аннотация переменной модуля

Экспериментальный профиль Linux x86_64: CLI build-annotated-vars,
linux-v5-annotated-vars1-xml221-r09, guard r09-annotated-vars-v1.
Позиционные параметры и явные лимиты verify прежние (ADR-041).

На уровне модуля точная одиночная аннотация &НаКлиенте или &НаСервере
может относиться к следующей физической строке с объявлением Перем.
Допускаются 1–64 различных простых имени через запятую либо одно имя
с Экспорт. Обязательна ровно одна конечная точка с запятой. После неё
допустим обычный однострочный комментарий; до следующей физической строки
аннотация не переносится. Вложенные объявления, инициализация, продолжения,
посторонние аннотации и изменения баланса ветвей не поддерживаются.

Такая строка потребляет ожидающую аннотацию, не создаёт фактов о методах
или переменных, не влияет на факты следующего метода и не меняет байты
исходника. При сомнении весь модуль остаётся unparsed. Старые профили
по-прежнему не принимают аннотацию перед Перем.

Уровень модуля здесь означает только состояние лексического анализатора
(вне метода и незакрытых скобок). Профиль не проверяет порядок объявлений
по правилам компилятора 1С и не строит семантику символов.
