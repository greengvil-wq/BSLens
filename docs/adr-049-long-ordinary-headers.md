# ADR-049: длинные обычные заголовки метода
`build-long-headers` выбирает новый экспериментальный профиль
`linux-v5-long-headers1-xml221-r09` и лексический режим `r09-long-headers-v1`.
Предыдущие профили не меняются.

В согласованном корпусе есть обычные заголовки из 17–20 физических строк.
Сохраняем правила смежных строк и продолжения после запятой. Для обычного
(не `Асинх`) заголовка разрешаем до 20 строк, сохраняя пределы 200 токенов,
8192 байта и 64 параметра. Только внутри полностью разобранного обычного
заголовка из 17–20 строк формальный идентификатор перед `=` может занимать
до 130 байт UTF-8, если после `=` стоит допустимое прежними правилами
скалярное значение. Лимиты остальных токенов не растут; прежнее исключение
для имени метода не меняется. Асинхронные заголовки по-прежнему ограничены
16 строками. Метод, его заголовок и ветвь используют исходные физические
байты; исходники не перезаписываются. Синтаксическая или контекстная
допустимость в компиляторе не утверждается.

Приёмка: переходы 16/17/20/21, оба размера идентификатора и отказ для
длинного значения, префикс `Асинх`, прежние лимиты, несовпадение
снимков старого и нового профилей, офлайн `verify`, именованная цитата MCP
вплоть до исходных CRLF, отказ без частичного списка методов, подмена фактов.
