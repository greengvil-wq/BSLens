# Проверки R05-A: от Git-коммита до модуля

Среда: облачная Linux, Rust 1.85.1, Git 2.47.3. Все репозитории в тестах временные
и авторские. База БСП, Windows, сетевые репозитории и пользовательские файлы не нужны.
Новые зависимости не добавлены; Cargo.lock не изменён.

## Пять новых сквозных проверок

1. Точный SHA → manifest → XML subset → конфигурация → группа Catalog → объект
   Items → ObjectModule. Рабочие XML/BSL испорчены после коммита, добавлен untracked XML:
   результат всё равно относится к коммиту. Сравниваются все bytes репозитория до/после.
2. Изменение только тела модуля создаёт другой commit-bound node ID. Старый ID
   отвергается новым контекстом, даже при одинаковой структуре XML.
3. Страницы с limit=1 обходят те же узлы, что общая допустимая страница, без пропусков
   и дубликатов. Контекст одинаков на всех страницах.
4. Неполный SHA/revision expression, Git budget и неподдержанный XML-класс дают
   типизированные ошибки без частичного дерева. Старый корректный коммит остаётся читаем.
5. Дополнительные bytes commit-префикса учитываются в текстовом бюджете страницы.
   Превышение возвращает TextBudget; меньшая страница сохраняет корректный next_offset.

Готовые проверки Git, XML, дерева и закрытой production-границы выполняются вместе
с интеграционными. Лексический слой, методы, MCP и запись снимков не подключены.

## Воспроизведение без сети

При наличии уже загруженных закреплённых зависимостей:

```sh
cargo test --offline --locked --features experimental-pipeline
cargo test --offline --locked --all-features
cargo test --offline --locked
cargo fmt -- --check
```

Исполненные результаты:

- `cargo test --offline --locked --features experimental-pipeline`: 30 успешно.
- `cargo test --offline --locked --all-features`: 36 успешно.
- `cargo test --offline --locked`: 1 успешно, экспериментальные слои выключены.
- `cargo fmt -- --check` и `git diff --check`: успешно.

Предупреждений компилятора в итоговых прогонах нет. Сеть для Cargo-прогонов не
использовалась. Независимое ревью выполняется отдельно.
Проверки не являются подтверждением production-готовности или полной поддержки БСП.
