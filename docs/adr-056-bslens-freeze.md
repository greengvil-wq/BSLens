# ADR-056. BSLens заморожен

Статус: **Принято**. Дата: 28.11.2026.

## Решение

BSLens заморожен: новые профили, задачи и PR по развитию не создаются. Основой системы приёмки становится [onec-navigator](https://github.com/greengvil-wq/onec-navigator) поверх форка gyrfalcon; слой приёмки размещается в отдельных Rust-модулях рядом с навигатором.

## Причины

- В эксперименте «применён ли патч» прямое сравнение хунков оказалось таким же точным и примерно в 19 раз дешевле по токенам, чем использование BSLens.
- В BSLens нет связей: вызовов, подписок, обработчиков и регистров. MCP предоставляет только metadata, tree и source.
- В onec-navigator эти связи есть и сверены аудитом 09.11.2026.

## Что сохраняется

- Протоколы `docs/acceptance-*.md`.
- Эталоны регресса: БСП — `2cbade82087f763633673d3bd77f36ab7bd8f3f1d926e573bd2173940cb5aa64`, СППР — `5578dead74acc155fa8fc13ae10d59fb8a0dc7aaa4a0c12c2f57d321643fe498`.
- [ADR-054](adr-054-method-hash-diff.md) и [ADR-055](adr-055-gitlab-adapter.md) как проектные материалы для новых модулей.

## Открытые PR и автономный цикл

PR №15 (C-1.1a, адаптер GitLab) и №18 (B-2.2.1b) не сливаются. Код адаптера GitLab переносится в модуль навигатора. Автономный цикл остановлен файлом STOP 28.11.2026.

## Последствия

Репозиторий становится только для чтения по смыслу; допускаются только критичные исправления.
