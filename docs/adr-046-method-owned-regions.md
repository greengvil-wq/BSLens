# ADR-046. Регион внутри метода

Экспериментальный профиль Linux: `build-method-regions`,
`linux-v5-method-regions1-xml221-r09`, guard `r09-method-regions-v1`.

Поддерживается лексическая пара `#Область` / `#КонецОбласти` внутри
одного метода с глубиной вложенности один, без хвостовых комментариев. До края метода внутренний
регион должен быть закрыт. Закрыть внешний для метода регион из тела
метода нельзя. Границы веток не могут пересекать границу региона, а
открытие/закрытие при висящих скобках не допускается. Для регионов модуля
и общего лимита глубины сохраняются старые правила.

Никаких фактов о регионах или выполнении кода не выпускается. Метод,
физические строки, байтовая цитата и путь его объявления по веткам
не изменяются. Старые профили и ограничения источников сохранены.
Неверная пара оставляет весь модуль неразобранным.
