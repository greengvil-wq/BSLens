# ADR-045. Мобильные условия и перенос списка «Перем»

Экспериментальный профиль Linux: `build-mobile-vars`,
`linux-v5-mobile-vars1-xml221-r09`, guard `r09-mobile-vars-v1`.

- Добавлены только три русских слова условия: `МобильныйАвтономныйСервер`,
  `МобильноеПриложениеКлиент`, `МобильноеПриложениеСервер`. Сохраняются уже
  действующие правила регистра, скобок, порядка ветвей и точных диапазонов.
  Условия не вычисляются, и никакая ветвь не объявляется выполняемой.
- Уже известная голая директива `&НаКлиенте` или `&НаСервере` над
  лексически верхнеуровневым `Перем` может относиться к списку обычных
  идентификаторов на 2–5 соседних физических строках. На каждой строке
  минимум одно имя, незаключительная заканчивается запятой, заключительная
  точкой с запятой; комментарии, экспорт, присваивания, повторы и переход
  через маркер препроцессора для продолженного списка не поддержаны.
  Лимиты: 64 имени, 128 байт на имя и 8192 байта на весь диапазон списка.
  Переменная не создаёт метод и забирает только свою директиву. Проверка
  не доказывает законность размещения по правилам компилятора.
- Старые профили, регионы и прочие виды синтаксиса не изменены. Отказ любой
  части декларации оставляет весь модуль неразобранным.

Источник: [1C:Enterprise Developer Guide 8.3.27, §4.8.1.1–4.8.1.2](https://1c-dn.com/library/tutorials/1c_enterprise_developer_guide_8_3_27/?sphrase_id=1895754).
